# UI

`packages/prompt-kit/src/ui` implements the authoring surface: the editor
(`editor/`), the lab shell (`lab/`), style settings (`style/`), the shared
visual substrate (`surface/`), and the read-only view (`view/`). The sibling
`src/annotations` area supplies the headless annotation schema and store the
lab's annotate surfaces build on.

## Decisions

### Headless-vs-React module boundary

**Decision.** Models, steps, transactions, and session logic are pure modules
with no runtime React or DOM dependency — the editor model, transactions, the
structure and list-item steps, autoformat, slash commands and the slash
session, edit navigation, the autosave controller, lab history, and style
settings. React components live in separate `.tsx` modules that consume them.

**Why.** The full shell logic is testable without a DOM.

**Applies to.** New editor logic lands headless-first; a React module may wrap
it, never contain it.

One known violation exists: `steps/structure-steps.ts` imports
`findUnnestLocation` from the client module `steps/node-mutations.ts`. New
code must not extend this coupling.

### Structural edits are pure step producers

**Decision.** A step producer reads the `PromptDocument`, never mutates it,
and returns steps plus a focus target. Returning `null` declines the gesture —
decline-by-null means fall through to the next handler, not failure.

**Why.** Producers compose into keymaps and menus without side effects, and
declining cleanly lets gestures layer.

**Applies to.** Every new structural gesture is a step producer with this
signature.

### Moves are remove-plus-insert preserving node ids

**Decision.** Reparenting uses the shared remove-then-insert helpers so the
same node ids re-attach at the new location. Multi-step gestures commit as one
transaction — a single undo entry.

**Why.** Id preservation keeps the canonical content hash stable across
nesting-only moves and keeps the caret in the moved block; one transaction per
gesture keeps undo aligned with user intent.

**Applies to.** Every new move or reparent gesture reuses the shared helpers
and commits atomically; a move that recreates nodes with fresh ids is a bug.
