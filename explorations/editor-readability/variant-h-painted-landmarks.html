H — Painted Landmarksprompt-editor readability exploration

G's structure carried wholesale — the gap ramp, the indent guides, the promoted chapter and phase landmarks, the quiet rail — with C's complete syntax palette painted back on at full working strength. Color now does the classifying (purple = structure, blue = attribute, amber = value, teal = code, gold = variable) while size and space keep doing the wayfinding.

  • one hue for structure — every tag is purple; the landmark hierarchy reads through brightness of that single hue: chapters #CBA6DE at 14px, phases #B48EC7 at 13.5px, minor tags #9A7CAC, and closing tags the dimmest purple step (#5D4F68) instead of G's gray — still the quietest thing on the line, but unmistakably the same family.
  • the wayfinder palette, balanced — attributes blue #85AECB, values amber #C09A78, brackets/=/quotes held at dim #6E7681 so words outshine punctuation; the hues sit at near-equal perceived lightness (~L 67–70) so no class shouts — gold alone was dimmed a step (#D9C578 → #CFBC74) because pure yellow reads brightest per unit lightness.
  • inline code gets a real dress — backtick spans and bare snake_case tool names (fit_section, add_annotation…) render teal #5FBCA5 on a faint teal-tinted chip with the ticks faded to 45%; {{variables}} go gold, italic, on a gold-tinted chip.
  • references ≠ structure — decoded inline refs like <instruction> render in teal (the reference color, chip-less) with quiet brackets — the same voice as code, deliberately distinct from the purple of real structural tags.
  • grammar tokens + the rail — APPLIED / NO-OP / ERROR / DELTA / ROUTES / E* / W* get a slightly-brighter-than-prose mono with .05em tracking, no color; the rail, gap ramp, measure, and chrome are untouched from G — gray with its single blue accent, never painted.
